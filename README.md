# Dynamic-AI
Dynamic AI is a tool that adds an AI assistant to your personal desktop. 

When downloading any version you will get the setup.exe file.
After the download finished you will need to connect an AI so that it works. (You can also use it for other things like: displaying the time, a music player and more)

More versions will come to make it better and better!

NOTE: You may get a windows pop up telling you it protected your PC, the program is completely safe so you wont need to worry about it just click more info and run anyway.
